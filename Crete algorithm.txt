خوارزمية تقدير الطالب بناءً على الدرجة النهائية

البداية
1. عرض رسالة ترحيب للمستخدم.
2. طلب إدخال درجة الطالب (رقم بين 0 و100) أو كلمة "خروج" لإنهاء البرنامج.
3. طالما أن المستخدم لم يدخل "خروج":
     3.1 إذا كانت القيمة المدخلة غير رقمية:
          عرض رسالة خطأ "الرجاء إدخال رقم صحيح أو كلمة خروج".
     3.2 إذا كانت القيمة المدخلة خارج النطاق 0-100:
          عرض رسالة خطأ "الدرجة يجب أن تكون بين 0 و100".
     3.3 وإلا:
          إذا كانت الدرجة >= 90:
              التقدير = "ممتاز"
          وإذا كانت الدرجة >= 75:
              التقدير = "جيد جدًا"
          وإذا كانت الدرجة >= 60:
              التقدير = "جيد"
          وإلا:
              التقدير = "ضعيف"
          عرض التقدير للمستخدم.
     3.4 اطلب من المستخدم إدخال درجة جديدة أو "خروج".
4. عند إدخال "خروج":
      عرض رسالة نهاية البرنامج.
